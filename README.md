# 順天太子會資料管理系統

瀏覽器版資料管理系統，包含法會登記、進香、捐款、查詢及列印。開啟 `index.html` 即可使用；部署時須保留 `assets` 資料夾及其相對路徑。國農曆轉換及雲端功能分別透過頁面引用的 lunar-javascript 與 Supabase SDK 提供，需要網路連線。

## 檔案結構

- `index.html`：頁面結構及外部套件載入。
- `assets/styles.css`：畫面及列印樣式。
- `assets/core.js`：共用狀態、資料儲存、法會及家庭登記。
- `assets/pilgrimage.js`：進香資料及列印。
- `assets/donations.js`：捐款資料及列印。
- `assets/search.js`：查詢介面與篩選。
- `assets/print.js`：法會查詢與列印內容、備份及初始化。

JavaScript 依上述順序以一般 script 載入，共用同一組頁面狀態。調整檔案順序時須注意相依性。

## 資料與數量

資料儲存在目前瀏覽器的 localStorage，可使用介面匯出備份，也可登入既有 Supabase 雲端功能。換瀏覽器或網址可能無法看到原本的本機資料，遷移前請先匯出備份。

家庭項目可以選擇成員並分別填寫數量；未選成員時，以「全戶共用數量」計算一筆。舊資料沒有個別數量時，仍使用原本的共同數量。查詢和列印的項目勾選互相獨立。
